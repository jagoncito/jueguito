# Referencias de personajes

Estas imágenes grandes sirven para conocer el aspecto de los personajes y reproducir los recortes técnicos. **No son sprites activos ni animaciones adicionales.** El conjunto vigente está en `../escala-juego/`.

- **Flavia:** Éowyn (rostro/presencia), Lagertha (peinado/porte), Faye (constitución de artesana). Se conserva la imagen base y las fuentes con las ocho vistas de reposo seleccionadas.
- **Unamahloni:** diseño acordado con el usuario, piel gris azulada, orejas humanas, ojos ámbar y cabello cobrizo. Imagen base y fuentes de las ocho vistas; tira NW dedicada para respetar la orientación y los accesorios.
- **Elfa del museo:** estudiosa, muy inteligente, memoria desde el nacimiento; gafas de bronce, trenza castaña y vestuario verde/marfil como propuesta visual. Fuente de ocho vistas libres.
- **Comerciante:** referencia física Arthas, adaptada a comerciante humano sociable y pícaro. Fuente de ocho vistas libres.
- **Pesca/cocina:** anciano excéntrico de inspiración Radagast, con identidad costera de Bītu. Fuente de ocho vistas libres.
- **Maestro enano:** Gimli como referente, revisado con pelo negro azulado, casco azul/latón, camisa índigo y delantal ocre. Fuente de ocho vistas libres. El primer concepto `maestro-y-quebraveta-fuente.png` se conserva como referencia de la creación del arma especial; no cuenta como sprite activo ni cambia la revisión vigente del enano.

Algunas fuentes originales contienen columnas de poses antiguas; `../escala-juego/fuentes.json` selecciona solo las ocho de reposo. Los PNG nativos, atlas, visores, prefabs, paquetes y láminas adicionales de NPC fueron retirados al simplificar el conjunto. Se mantienen las fuentes necesarias para regenerar los sprites vigentes y las referencias de cuerpo completo.

El arte anterior del dragón, incluido su original, se ha retirado por solicitud posterior del usuario. Las nuevas fuentes y poses están en `../dragon/`; el historial de Git se conserva.
