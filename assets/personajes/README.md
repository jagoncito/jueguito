# Recursos de personajes

## Unamahloni

[unamahloni-idle.png](unamahloni-idle.png) es el primer recurso gráfico generado para el maestro alquimista/herboristero Veyari.

- PNG RGBA con fondo transparente; dimensiones originales: **1143 × 1376 píxeles**.
- Una pose quieta de cuerpo entero, orientada hacia el jugador desde una vista ligeramente elevada.
- Piel gris azulada, orejas humanas, ojos ámbar y cabello de tono similar; cuaderno y utensilios de alquimia.
- Imagen independiente, sin cuadrícula de fotogramas ni animación. Las demás direcciones y animaciones no se han creado.

Se conserva el original generado, sin recortar ni cambiar tamaño. La resolución del personaje dentro del juego se decidirá con el motor y los escenarios; para mantener los bordes del estilo pixel art al escalar, usar filtrado por vecino más cercano (*nearest-neighbor*).

Esta imagen es un recurso visual para la futura implementación. Su ropa y accesorios pueden revisarse; las decisiones de diseño vigentes están en [DISENO.md](../../DISENO.md). La creación del recurso no inicia la programación del juego.
