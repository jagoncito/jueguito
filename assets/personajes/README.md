# Recursos de personajes

## Protagonista: dragón bípedo

El usuario elige el dragón del avatar como protagonista el 9 de octubre. Tras revisar la primera adaptación, solicita proporciones nuevas y ocho vistas, conservando sus rasgos faciales. Reposo, marcha, minería, tala y palín usan poses completas con cola conectada, ya integradas en la prueba. [Ficha y archivos](dragon-avatar/README.md). Esta elección sustituye al protagonista humano anterior; Unamahloni mantiene su propio papel.

## Unamahloni — versión original pixel art

[unamahloni-idle.png](unamahloni-idle.png) es el primer recurso gráfico generado para el maestro alquimista/herboristero Veyari.

- PNG RGBA con fondo transparente; dimensiones originales: **1143 × 1376 píxeles**.
- Una pose quieta de cuerpo entero, orientada hacia el jugador desde una vista ligeramente elevada.
- Piel gris azulada, orejas humanas, ojos ámbar y cabello de tono similar; cuaderno y utensilios de alquimia.
- Imagen independiente, sin cuadrícula de fotogramas ni animación. Las demás direcciones y animaciones no se han creado.

Se conserva el original generado, sin recortar ni cambiar tamaño. La resolución del personaje dentro del juego se decidirá con el motor y los escenarios; para mantener los bordes del estilo pixel art al escalar, usar filtrado por vecino más cercano (*nearest-neighbor*).

## Dirección visual vigente

Todo el juego será **pixel art**, con **vista desde arriba isométrica cenital**: cámara elevada en tres cuartos, tomando Diablo IV como referencia de perspectiva.

El recurso original se conserva intacto como primer boceto. Su cámara solo está ligeramente elevada y el cabello no se ha ajustado al peinado liso acordado; esas adaptaciones quedan pendientes. Las dos variantes ilustradas se eliminaron tras comparar estilos.

**Generación de imágenes en pausa por petición del usuario.** No se ha creado una nueva imagen ni iniciado programación para adaptar este recurso. Las decisiones vigentes están en [DISENO.md](../../DISENO.md).
