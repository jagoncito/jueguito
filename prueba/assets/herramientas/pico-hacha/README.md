# Pico–hacha de hierro: copia para Godot

Recurso registrado para el proyecto `prueba/project.godot`. PNG, metadatos, escena y script son copias idénticas de los [recursos originales y sus instrucciones](../../../../assets/herramientas/pico-hacha/README.md).

Abre `scenes/herramienta.tscn` y pulsa **F6** para revisar agarre y escala. Las texturas de pico y hacha se pueden sustituir por separado conservando el mango y el pivote. Se suministra un rig de una proyección, no todas las animaciones direccionales del personaje.
