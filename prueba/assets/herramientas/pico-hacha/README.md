# Pico–hacha de hierro: copia para Godot

Recurso registrado para el proyecto `prueba/project.godot`. PNG, metadatos, escena y script son copias idénticas de los [recursos originales y sus instrucciones](../../../../assets/herramientas/pico-hacha/README.md).

Abre `scenes/herramienta.tscn` y pulsa **F6** para revisar agarre y escala. Las texturas de pico y hacha se pueden sustituir por separado conservando el mango y el pivote. El original conserva su revisión de una proyección; `pico-hacha-vistas.png` y su JSON añaden ocho perspectivas registradas para el dragón, con tres componentes y contactos por vista. Las mejoras de materiales todavía no son jugables.
